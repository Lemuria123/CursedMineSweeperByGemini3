# Agent Instructions

## CRITICAL RULE: 不确定需求时必须问用户

在修改任何代码之前，如果对需求、预期行为、边界情况有任何不确定，**必须先向用户提问确认**，绝对禁止猜测后直接改代码。这条规则优先级高于所有其他规则。
